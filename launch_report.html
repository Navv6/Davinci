작성 기준: 현재 코드베이스 실제 탐색 결과 기반

1. 구현 현황 보고서

  • 현재 프로젝트는 3D 아이디어 그래프를 생성하고 노드를 추가·편집·삭제하는 인터랙티브 노트 UI까지 구현되어 있다.
  • 핵심 진입점은 app/page.tsx, components/desktop/DavinciExperience.tsx, components/desktop/IdeaSpace.tsx, components/mobile/IdeaSpace.tsx에 집중되어 있다.
  • 프론트엔드: 데스크톱/모바일 분기, 주제 입력, 그래프 시작, 노드 추가·선택·수정·삭제, 미니맵, 사이드바, 모바일 드로어, 메모 UI 구현 완료
  • 백엔드/API: app/api 없음, 서버 액션 없음, 외부 API 호출 없음. 서버 기능 미구현
  • DB/저장: DB 연결 코드 없음, Supabase/Prisma/Drizzle 없음, 현재 데이터는 전부 컴포넌트 메모리 상태
  • 인증/회원: 로그인, 회원가입, 세션, 권한 코드 없음
  • AI 기능: OpenAI 등 AI SDK 연동 없음, 실제 AI 기능 미구현
  • 결제/구독: Stripe 등 결제 코드 없음, 플랜/구독 상태/사용량 제한 없음
  • 정책 문서: 개인정보처리방침.txt, 이용약관.txt 존재. 하지만 서비스 라우트 및 링크 노출 없음
  • 배포: GitHub Pages 정적 배포 워크플로우 존재, next build, eslint 통과
  • 운영: 에러 로깅, 모니터링, 지원 채널, 관리자 도구 없음
  • 요약하면 현재 상태는 서비스 MVP가 아니라 공개 가능한 인터랙티브 데모에 가깝다.

2. 출시 차단 이슈 리스트

  • 저장/불러오기 부재: 현재 가장 큰 출시 차단 요소다. 사용자가 만든 노트가 유지되지 않는다.
  • 사용자 식별 부재: 로그인 없이 데모는 가능하지만, 실제 서비스로 가면 사용자별 데이터 분리가 불가능하다.
  • 서버 기능 부재: 현재 정적 배포 구조라 AI 호출 보호, 결제 웹훅, 안전한 저장 API를 둘 수 없다.
  • 제품 핵심 플로우 미완성: 진입 → 생성 → 저장 → 다시 열기 흐름이 완성되지 않았다.
  • 정책 문서 비노출: 문서는 파일로만 있고 서비스 UI 어디에서도 접근할 수 없다.
  • 운영 최소장치 부재: WebGL 실패 fallback, 에러 추적, 사용자 문의 경로가 없다.
  • 수익화 구조 전무: 결제/구독을 붙여 출시할 상태는 아니다.

3. MVP 출시 범위 정의서

  • 권장 MVP 정의: 로그인 없이 주제 기반 아이디어 그래프를 만들고, 브라우저에 자동 저장되며, 다시 열 수 있는 개인용 아이디어 노트
  • MVP 필수 범위: 랜딩 진입, 새 그래프 시작, 노드 추가·수정·삭제, 메모 작성, 자동 저장, 새로고침 후 복구, 정책 문서 노출, 에러 fallback
  • MVP 제외 범위: AI 확장 기능, 결제/구독, 소셜 로그인, 무료/유료 세션 제한, 고급 공유/협업, 노드 자유 이동, 모바일 앱화, 모션캡처
  • 현실적 판단: 퍼블릭 데모로는 지금도 가능하지만, 실사용 MVP로 보려면 최소 저장 기능이 먼저 필요하다.

4. 우선순위 개발 백로그 (P0/P1/P2)

P0

  • 브라우저 자동 저장: topic, nodes, edges, memo를 localStorage에 저장하고 복구
  • 복구 UX 추가: 이전 작업 이어하기 / 새로 시작 선택 UI 제공
  • 정책 문서 라우트화: privacy, terms 페이지와 홈/푸터 링크 추가
  • WebGL 실패 fallback: 3D 초기화 실패 시 안내 UI 제공
  • 기본 에러 로깅: 최소 에러 화면과 추적 장치 추가

P1

  • Supabase 저장 구조 도입: 브라우저 저장에서 클라우드 저장으로 전환
  • 이메일 로그인 도입: 사용자별 데이터 분리
  • 온보딩 템플릿 제공: 예시 그래프 2~3개 제공
  • 제품 소개/랜딩 정보 보강: 기능 설명, 베타 안내, 문의 링크 추가

P2

  • AI 아이디어 확장
  • 결제/구독
  • 노드 자유 이동
  • 데스크톱/모바일 그래프 로직 공통화

5. 바로 착수 가능한 첫 작업 10개

  1. localStorage 기반 그래프 자동 저장 포맷을 확정한다.
  2. 데스크톱 IdeaSpace에 자동 저장 로직을 붙인다.
  3. 모바일 IdeaSpace에 자동 저장 로직을 붙인다.
  4. 앱 첫 진입 시 저장 데이터 복구 로직을 추가한다.
  5. 홈 화면에 이전 작업 이어하기 / 새로 시작 버튼을 추가한다.
  6. 개인정보처리방침과 이용약관을 app 라우트 페이지로 만든다.
  7. 메인 화면 하단에 개인정보처리방침 / 이용약관 / 문의 링크를 추가한다.
  8. 3D 렌더링 실패 시 보여줄 fallback UI를 만든다.
  9. app/error.tsx와 기본 에러 화면을 추가한다.
  10. README를 실제 제품 기준으로 다시 정리해 현재 출시 범위와 제외 기능을 명시한다.
